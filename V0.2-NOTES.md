# BuildRight v0.2 implementation notes

## Architectural change
`BuildEngine.kt` is a pure calculation layer separated from Compose UI. This is intentional: later engines, tests, exports and AI-assisted project setup can call the same deterministic formulas without duplicating UI logic.

## Current shed assumptions
- Rectangular footprint.
- Joists span the entered width and are spaced along the entered length.
- Walls use a planning stud count at the selected on-center spacing plus a corner/opening framing allowance.
- Bottom plate + double top plate = three perimeter runs for preliminary takeoff.
- Roof is a centered symmetrical gable with ridge along the entered length.
- Roof area currently excludes eave/rake overhangs.
- A 4×8 sheet is treated as 32 square feet for takeoff.
- Door/window area is deducted from wall sheathing/siding area, but opening framing is added to the stud allowance.

These assumptions are displayed as planning notes; they are not structural-design decisions.
