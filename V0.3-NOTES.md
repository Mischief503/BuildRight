# BuildRight v0.3 — Powerful Shed Builder

## Added
- Saved foundation system: Pier / Blocks, Skids, or Concrete Slab
- Foundation support spacing, skid count/size, and slab thickness planning inputs
- Saved lumber member selections for floor joists, studs, rafters and ridge
- Preferred stock length for plate/ridge purchasing
- Gable and shed-roof geometry modes
- Eave and rake overhangs included in roof area and sheathing takeoff
- Door and window wall assignment
- Wall-by-wall framing summaries
- Foundation/floor/wall/roof/weather takeoff categories
- Generated cut-plan lines for joists, studs, plates, rafters and ridge stock
- Generated material synchronization still preserves prices by material name
- v0.2 projects remain loadable because all v0.3 fields have backward-compatible defaults

## Important scope
BuildRight v0.3 is a planning/takeoff engine. It does not certify structural adequacy, code compliance, footing capacity, header sizing, connection schedules, wind/seismic design or permit approval.

## Next target
v0.4 should add a visual plan engine, multiple individually positioned doors/windows, exact wall elevations, field/build mode, project photos/receipts, and export/import.
